## 🧱 How I Structure a MERN App

```text
project/
├── client/                 # React / Next.js frontend
│   ├── components/         # Reusable UI
│   ├── hooks/              # Custom hooks
│   └── services/           # API calls
└── server/                 # Node + Express backend
    ├── controllers/        # Request handling
    ├── models/             # Mongoose schemas
    ├── routes/             # API routes
    ├── middleware/         # Auth, validation, errors
    └── config/             # DB + env setup
```
